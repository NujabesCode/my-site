# my-site

홍길동의 자기소개를 담은 한 페이지짜리 정적 웹사이트입니다.

## 배포 주소

https://nujabescode.github.io/my-site/

## 로컬에서 보기

빌드 과정이 없는 순수 HTML/CSS/JS 사이트라서 바로 열어 볼 수 있습니다.

**방법 1. 파일 바로 열기**

`index.html`을 더블클릭해서 브라우저로 엽니다.

**방법 2. 로컬 서버로 열기**

프로젝트 폴더에서 아래 명령을 실행한 뒤 브라우저에서 http://localhost:8000 에 접속합니다.

```bash
python -m http.server 8000
```

Node.js를 쓴다면 `npx serve .`로도 열 수 있습니다.
